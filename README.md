# Plant Reminder

A personal Progressive Web App for reminding yourself to water, fertilize, and mist your houseplants.

## Status

- **Phase 1 (current)**: Local-only MVP. Plants and schedules stored in browser localStorage. Works offline as a PWA.
- **Phase 2**: Google Sign-In + Drive sync for cross-device data.
- **Phase 3**: Firebase Cloud Messaging push notifications via a daily GitHub Actions cron.

## Local development

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # produces dist/
npm run preview        # serve the production build locally
```

## Deploying

Push to `main`. The `Deploy to GitHub Pages` workflow builds and publishes to GitHub Pages.

One-time setup (after creating the GitHub repo):
1. Repo Settings → Pages → Source: **GitHub Actions**.
2. (Optional) Repo Settings → Pages → Custom domain.

## Stack

- Vite + React + TypeScript
- `vite-plugin-pwa` (service worker, install manifest, offline cache)
- `date-fns` for scheduling math
- Hosted free on GitHub Pages

## Schedule model

Each plant can independently configure water, fertilize, and mist tasks:

- `intervalDays`: e.g. 7 for weekly watering.
- `activeMonths`: optional list of 1-12 month numbers. If set, the next-due date skips inactive months — useful for fertilizer in spring/summer only.

Marking a task done sets `lastDone[task] = today`; the next-due date becomes `lastDone + intervalDays`, then advances to the first active month if needed.
